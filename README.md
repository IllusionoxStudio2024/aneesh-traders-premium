# Aneesh Traders — Premium Website

Next.js + TypeScript + Tailwind website built from the supplied Aneesh Traders website brief.

## Run
1. Open this folder in a terminal.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Important before launch
- Replace demo Unsplash imagery with approved Aneesh Traders/product/project photos.
- Add genuine leadership photo and approved message for Aneesh Pai.
- Replace client text treatments with approved client logos where permission exists.
- Add final product specifications, catalogues, certifications and exact brand assets.
- Connect the enquiry form to the client's email/CRM.
- Add confirmed Google Maps embed and final social links.
- Add analytics, final SEO metadata and production domain.

The supplied brief explicitly requested genuine project/client photography and warned against placeholder testimonials, so the site deliberately marks those asset areas rather than inventing them.
